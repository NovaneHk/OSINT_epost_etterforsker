# Nova Trace Agent Instructions

This repository contains Nova Trace, a premium B2B OSINT dashboard.

When acting as an AI coding agent:

1. Read `.github/copilot-instructions.md` first.
2. Read relevant files in `.github/instructions/`.
3. Read `docs/nova-trace-frontend-spec.md`.
4. Do not build features outside the current sprint.
5. Prefer small, verifiable edits.
6. Run validation commands before reporting completion.
7. Never report success if build, lint, or typecheck fails.
8. If a dependency or shadcn component is missing, report it and install/add it only if needed for the current sprint.
9. Do not build auth, backend, database, billing, or full Playbooks in Sprint 1.
10. Use mock data first, but shape it to match the documented future API contracts.
